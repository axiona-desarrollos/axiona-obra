# Muebles 3D reales de Axiona Obra

Modelos de [Poly Haven](https://polyhaven.com) con licencia **CC0** (dominio público): se pueden usar, modificar y vender sin atribución. Igual les damos el crédito.

Se descargaron en resolución 1k y se optimizaron con glTF-Transform 4.5 (`optimize --compress meshopt --texture-compress webp --texture-size 512`). Cada archivo pesa entre 70 y 570 KB; los once suman unos 1,9 MB y solo se descargan al abrir el 3D.

| Archivo | Modelo de Poly Haven | Se usa como |
|---|---|---|
| modern_arm_chair_01.glb | Modern Arm Chair 01 | Poltrona (moderno, cálido, nórdico, campestre) |
| mid_century_lounge_chair.glb | Mid Century Lounge Chair | Poltrona (lujo) |
| sofa_02.glb | Sofa 02 | Sofá (lujo) |
| modern_coffee_table_01.glb | Modern Coffee Table 01 | Mesa de centro |
| coffee_table_round_01.glb | Coffee Table Round 01 | Mesa de centro (lujo) |
| dining_chair_02.glb | Dining Chair 02 | Sillas del comedor |
| potted_plant_01.glb, potted_plant_02.glb, potted_plant_04.glb | Potted Plant 01, 02 y 04 | Plantas |
| side_table_01.glb | Side Table 01 | Mesa de noche |
| wooden_display_shelves_01.glb | Wooden Display Shelves 01 | Biblioteca |

Si un modelo no carga (sin señal la primera vez), el mueble se arma con piezas simples como antes.
